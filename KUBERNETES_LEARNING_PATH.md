# Kubernetes learning path

## Step 1 — build the foundations manually

Start with [Kubernetes Foundations Lab](kubernetes-foundations-lab/README.md).

You will create the kind cluster yourself, inspect the Docker node containers and Kubernetes system components, then work through Pod, Deployment, Service, DNS, ConfigMap, Secret and troubleshooting exercises one object at a time.

## Step 2 — build the platform

Continue with [ForgePaaS Lab](forgepaas-lab/README.md) only after completing the Step 1 graduation checklist.

ForgePaaS assumes Kubernetes basics and applies them to a production-style platform: a Python control plane, delivery pipelines, observability, reliability, and eventual AWS/Terraform infrastructure.
