# System-design practice tracker

Produce one timed design packet for each prompt below. Use a consistent one-page template: functional/non-functional requirements, estimate, API/data model, diagram, critical-path deep dive, failures, telemetry, security and trade-offs.

1. Design GitHub Actions
2. Design a Kubernetes Scheduler
3. Design a Build System
4. Design a Package Repository
5. Design a Logging Platform
6. Design a Monitoring Platform
7. Design a Distributed Cache
8. Design Object Storage
9. Design Kafka-like Messaging
10. Design a Highly Available Database

Use a 20-week cadence to reach the playbook’s **40+ sessions**: first design (one session), reviewer challenge (one session), then two ForgePaaS-specific designs or redesigns each week. Keep the most useful diagrams and ADRs in `docs/` as portfolio evidence.
