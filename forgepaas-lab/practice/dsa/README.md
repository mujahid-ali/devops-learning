# DSA practice tracker — 180 medium-focused problems

DSA supports the interview portion of the playbook; it is not hidden inside the platform codebase. Put solutions in language-specific folders with a test or a written complexity proof.

| Topic | Target | Evidence standard |
|---|---:|---|
| Arrays | 25 | invariant and time/space complexity written before coding |
| Strings | 20 | edge cases include Unicode/empty input where relevant |
| HashMap | 20 | collision/lookup trade-off explained |
| Trees | 30 | recursive and iterative traversal understood |
| Graphs | 20 | visited-state, components and shortest-path choice justified |
| Binary Search | 15 | search-space invariant stated |
| Heap | 15 | heap contents and operation cost explained |
| Sliding Window | 15 | window expansion/shrink condition stated |
| Miscellaneous | 20 | pattern classification and retrospective note |
| **Total** | **180** | one mistake pattern and one revisit date per problem |

Suggested cadence: 9 problems/week for 20 weeks. Once a week, re-solve one previously failed problem without notes and explain it aloud in ten minutes.
