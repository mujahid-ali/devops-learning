# Career evidence tracker

This project supports—not replaces—the career activities in the playbook. Update this file weekly with links to sanitized evidence and lessons learned.

## STAR story backlog

- RTC to GitHub migration
- Build-time reduction from two hours to twenty minutes
- MCP-10 / RHEL9 enablement
- OpenStack lifecycle validation
- Security hardening and SELinux
- Production incident resolution
- Leadership and ownership examples

For each story, write the situation/task in two sentences, then quantify the action, technical trade-off, impact and what you would improve. Rehearse it against skeptical follow-up questions.

## Delivery checklist

- Resume quantifies ownership, architecture decisions and impact.
- LinkedIn headline and experience match the Platform Engineer positioning.
- GitHub repository has a clear README, architecture diagram, setup guide, ADRs and sanitized incident notes.
- Track 10 mock interviews, 30 quality applications and at least 5 final interview loops.
- Update the company and weekly progress trackers from the original playbook; do not publish private application notes to this repository.
