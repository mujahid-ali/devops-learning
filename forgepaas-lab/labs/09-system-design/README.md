# Lab 09 — Staff-level system design

Complete the ten design packets in `practice/system-design/`. Each packet is 45–60 minutes and must include requirements, capacity estimate, APIs/data model, components/data flow, failure modes, observability and explicit trade-offs.

Use ForgePaaS as a recurring reference point:

- What would make the system multi-tenant?
- Which state is strongly consistent and which can be eventually consistent?
- Where is the availability boundary?
- How would deployment and rollback occur safely?
- What metric proves the system is healthy from the user’s perspective?

After every packet, spend ten minutes defending the design against a reviewer who asks about scale, cost, security, operations and a regional outage.
